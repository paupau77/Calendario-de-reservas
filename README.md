# Calendario de Reservas🗓️

Calendario interactivo y moderno para gestionar reservas.  
Diseño oscuro, navegación entre meses, selección y bloqueo de fechas reservadas.

---

## Características✨

- Navega entre meses con flechas.  
- Días reservados marcados y no seleccionables.  
- Selección de fecha para reservar.  
- Diseño responsivo y visualmente atractivo.

---

## Cómo usarlo🤔

1. Clona o descarga este repositorio.
2. Abre `index.html` en tu navegador favorito.
3. Navega entre meses, selecciona una fecha y presiona "Reservar fecha".

---

## Archivos💓

- `index.html` - Estructura y contenido de la página.  
- `styles.css` - Estilos para el calendario.  
- `app.js` - Lógica para la navegación y reservas.
